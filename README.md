# C-Breeze Capital — GreenExpress

Parent-company repository for **C Breeze Enterprises LLC**. The GreenExpress platform codebase (customer storefront, merchant dashboard, admin panel, and API backend) lives in this repo.

- **Live app:** https://ef5d2c4ae9113753571b85ddf95ab4dd.ctonew.app
- **Stack:** TanStack Start (React + Vite), Bun, SQLite (bun:sqlite), JWT auth, SSE streaming
- **Run locally:** `bun install && bun run dev` (or `bun run publish` to build + serve on port 3000)
- **Mobile:** Capacitor iOS/Android wrappers in `ios/` and `android/`
